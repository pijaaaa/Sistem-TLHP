# R0 — Inventaris & Pembersihan

## Konteks
Sistem e-TLHT versi awal (M0–M11) sudah selesai. Kita remodel besar mengikuti `docs/roadmap-remodel.md` (salin dari file roadmap-remodel.md ke `docs/`). Domain baru: Temuan > Action Plan (per departemen) > Tindak Lanjut. Data development boleh direset.

## Tugas
1. Git: buat tag `v1-m11` di commit sekarang, lalu branch `remodel/etlht`.
2. **Inventaris** (tulis ke `docs/remodel-inventory.md`): daftar semua model, migration, service, policy, controller, resource, route, test, halaman FE, komponen FE, hook, dan menu seed. Tandai tiap item **KEEP / REMOVE / REWORK** memakai tabel pemetaan lama → baru di roadmap bagian 9.
   - KEEP: auth, menu + izin dinamis, master departemen/karyawan, `CacheService`, `ApiResponse`, `DocumentService` + tabel `documents`, `AuditLogger`/audit trail, komponen UI reusable, `DataTable`, `FileUploader`, `PermissionMatrix`, exporter Excel, layout/sidebar dinamis.
   - REMOVE: distribusi temuan, tindak lanjut lama (`action_plans` lama), review tindak lanjut lama, evidence, assessment Manager IA, ronde temuan, verifikasi/closing Manager SPI lama, status `CASE_CLOSED`, dashboard widget & export yang bergantung modul tersebut.
   - REWORK: `findings` (R2), role enum (R1), seeder menu/izin (R1), dashboard (R10).
3. **Hapus** semua item REMOVE: model, service, controller, route, policy, resource, test, halaman FE, hook, menu seed. Hapus tabel lama dari migration (rapikan migration agar `php artisan migrate:fresh --seed` bersih; tabel `findings` lama dan `audit_reports` dibiarkan sementara sampai R2 menimpa).
4. Ganti **seluruh** isi `AGENTS.md` dengan file `AGENTS.md` dari paket remodel (sudah menggabungkan aturan teknis lama dan aturan remodel; jangan menyisakan AGENTS.md lama). Salin `roadmap-remodel.md` ke `docs/roadmap-remodel.md`.
5. Pastikan menu lama yang dihapus tidak muncul lagi di sidebar dan seeder tidak mereferensikan modul yang dihapus.

## Acceptance criteria
- `migrate:fresh --seed` sukses; login, master departemen/karyawan, manajemen akses, audit trail masih jalan.
- Test untuk modul KEEP lolos; test modul REMOVE ikut terhapus (bukan di-skip).
- `docs/remodel-inventory.md` lengkap dan dipakai sebagai acuan R1–R11.
- Tidak ada referensi sisa ke class/tabel yang dihapus (`grep` bersih).

## Larangan
Jangan membangun fitur baru. Jangan menghapus modul KEEP. Jangan mengubah `DocumentService`, `CacheService`, atau `AuditLogger` selain memperbaiki referensi yang rusak.
