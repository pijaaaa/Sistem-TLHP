# R10 — Tampilan Utama, Monitoring & Laporan, Dashboard

## Konteks
R0–R9 selesai. Saatnya merapikan tampilan sesuai dokumen: menu Temuan bertingkat, dashboard baru, monitoring & laporan. Baca roadmap bagian 8 dan aturan 9.

## Tugas
**Backend**
1. Endpoint tree ringan: `GET /findings/{id}/tree` (AP) dan `GET /action-plans/{id}/follow-ups` (TL) dimuat **lazy** saat dibuka; semuanya lewat visibility scope; cache pendek.
2. **Monitoring & Laporan** (menu `reports`), agregasi di SQL + `CacheService` (TTL pendek, invalidasi saat data berubah):
   - rekap per departemen (jumlah AP, TL, progres rata-rata, selesai, terlambat),
   - keterlambatan (TL belum selesai & lewat `target_date`, hari terlambat),
   - umur temuan (`finding_date`; kelompok umur),
   - risiko (jumlah AP per tingkat risiko + total potensi kerugian Rp dan USD terpisah, tanpa konversi),
   - filter tahun buku/sumber/departemen/status.
3. **Export Excel** (reuse exporter): rekap temuan, rekap per departemen, keterlambatan, risiko, log aktivitas — mengikuti scope visibilitas role. Tidak ada unduhan massal dokumen.
4. **Dashboard per role**: tugas yang menunggu (dari `inbox_tasks`), notifikasi terbaru, ringkasan tindak lanjut (jumlah per status, progres). Widget per role: admin_spi/internal_audit (temuan per status, AP menunggu PIC, antrian review SPI), manager_dept (antrian persetujuan, TL terlambat), PIC (TL menunggu aksi/revisi), kepala_spi (menunggu status eksternal), manager_ia/direksi (ringkasan seluruh temuan). Cache per role/user.
5. Ganti nama tampilan audit trail menjadi **Log Aktivitas** (menu `audit_trail` tetap); pastikan semua aksi alur R2–R8 tercatat.
6. Test: agregasi sesuai scope role, export tidak membocorkan data di luar scope, cache terinvalidasi, tidak ada endpoint zip/bulk download.

**Frontend**
7. `/temuan`: **tampilan bertingkat** Temuan > Action Plan > Tindak Lanjut (komponen reusable `ExpandableTree`, baris dapat dibuka-tutup, data anak dimuat saat dibuka); klik TL membuka `FollowUpDetailModal` (pop-up, tanpa pindah halaman).
8. `/dashboard` dengan `DashboardLayout` + widget per role (`StatCard`, `TaskList`, `ProgressBar`, `ChartCard`), konfigurasi widget di satu file.
9. `/laporan`: tab Rekap Departemen, Keterlambatan, Umur Temuan, Risiko, filter reusable, `ExportButton`.
10. `/log-aktivitas`: tabel + filter + `JsonDiff` (tetap dari versi awal, sesuaikan istilah).

## Acceptance criteria
- Tree temuan memuat anak secara lazy dan cepat; pop-up TL tidak berpindah halaman.
- Laporan, dashboard, dan export hanya menampilkan data sesuai scope role.
- Request kedua dashboard/laporan dilayani dari cache.

## Larangan
Jangan query agregat berat tanpa index/cache. Jangan menambah unduhan massal. Jangan melonggarkan visibilitas demi laporan.
