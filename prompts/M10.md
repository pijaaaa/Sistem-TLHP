# M10 — Audit Trail, Dashboard per Role, Export Laporan

## Konteks
M0–M9 selesai. `AuditLogger` sudah dipanggil di milestone sebelumnya (mungkin berupa stub).

## Tugas
**Backend**
1. Tabel `audit_logs`: id, user_id, role, action, entity_type, entity_id, finding_id (nullable, untuk filter), old_values (json), new_values (json), ip, user_agent, created_at. Implementasikan `AuditLogger` sungguhan; pastikan semua transisi status, review, upload, assessment, closing tercatat. Audit log append-only (tanpa update/delete).
2. API audit trail: filter user, aksi, entitas, temuan, rentang tanggal; paginasi. Akses: admin_spi, manager_ia, manager_spi (semua); manager_dept dan staff hanya log pada temuan yang terlihat oleh mereka (via scope visibilitas).
3. Dashboard endpoint per role (ringkas, agregasi di SQL, cache TTL pendek per role/user lewat `CacheService`, invalidasi saat event relevan):
   - admin_spi: jumlah temuan per stage, per auditor;
   - manager_ia: temuan menunggu assessment, distribusi status, progress per departemen;
   - manager_dept: progress temuan departemen, antrian review tindak lanjut dan evidence;
   - staff_dept: temuan saya, tindak lanjut menunggu aksi/revisi;
   - manager_spi: antrian verifikasi, temuan closed vs open.
4. Export Excel (maatwebsite/excel atau setara, via queue sync atau chunk agar ringan): rekap temuan (filter stage/status/departemen/auditor), rekap progress per departemen, audit trail. Hasil sesuai visibilitas role.
5. Test: log tercatat pada tiap aksi kunci, scope audit log, export tidak membocorkan data di luar scope.

**Frontend**
6. Dashboard per role memakai `StatCard`, `ChartCard` (library chart ringan), `ProgressBar` reusable; satu komponen `DashboardLayout` dengan widget per role dari konfigurasi.
7. Halaman Audit Trail (`DataTable` + filter reusable, tampilan diff `JsonDiff`).
8. Tombol Export reusable (`ExportButton`) pada halaman daftar.

## Acceptance criteria
- Dashboard tiap role menampilkan data sesuai scope dan cepat (request kedua dari cache).
- Audit trail lengkap dan tidak bisa diubah.
- Export Excel terunduh dan sesuai filter.

## Larangan
Jangan menambah notifikasi/deadline/SSO. Jangan query agregat berat tanpa index/cache. Jangan ekspos audit log lintas scope.
