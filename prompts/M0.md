# M0 — Fondasi Proyek

## Konteks
Proyek baru: sistem tindak lanjut temuan audit eksternal. Baca `docs/roadmap.md` (salin dari roadmap.md) dan `AGENTS.md`. Belum ada kode.

## Tugas
**Setup**
1. Monorepo: `backend/` (Laravel 11) dan `frontend/` (Vite + React + TypeScript + Tailwind + TanStack Query + React Router + axios).
2. Salin `_AGENTS.md` menjadi `AGENTS.md` di root; salin roadmap ke `docs/roadmap.md`.
3. Konfigurasi `.env.example` untuk MySQL Laragon, `CACHE_STORE=file`, disk `private`, CORS untuk dev Vite.

**Backend**
4. Struktur: `app/Enums`, `app/Services`, `app/Support`, `app/Http/Resources`, `app/Policies`.
5. `App\Support\CacheService`: `remember(string $group, string $key, Closure $cb, ?int $ttl)`, `forget($group, $key)`, `flushGroup($group)` memakai version key per group (tanpa cache tags).
6. `App\Support\ApiResponse` (format sukses/error konsisten) dan exception handler JSON untuk `/api/*`.
7. `config/upload.php`: mime yang diizinkan (pdf, doc/docx, xls/xlsx, jpg, png), ukuran maks (default 10 MB).
8. Rancang helper `AuditLogger::log(...)` (stub, tabel dibuat di M10) agar milestone berikutnya bisa memanggilnya.
9. Endpoint `GET /api/v1/health`.

**Frontend**
10. Struktur: `src/api`, `src/hooks`, `src/components/ui`, `src/components/shared`, `src/layouts`, `src/pages`, `src/lib`.
11. Komponen dasar reusable: `Button`, `Input`, `Select`, `Textarea`, `FormField`, `Modal`, `ConfirmDialog`, `Badge/StatusBadge`, `DataTable` (pagination, sort, search, loading, empty state), `PageHeader`, `FileUploader` (multi file + label per file), `Spinner`, `Toast`.
12. `api/client.ts` (axios + interceptor error), `QueryClientProvider` dengan default `staleTime` 60 detik.
13. `AppLayout` (sidebar + topbar) kosong dengan menu placeholder.

## Acceptance criteria
- `php artisan serve`/Laragon dan `npm run dev` jalan; halaman utama memanggil `/health` dan menampilkan statusnya.
- `CacheService` punya unit test (remember, forget, flushGroup).
- `DataTable` dan `FileUploader` dirender dalam halaman demo `/dev/components`.
- Lint dan build FE lolos; test BE lolos.

## Larangan
Jangan buat auth, model bisnis, atau halaman fitur apa pun. Jangan pakai cache tags. Jangan pakai library UI berat tambahan tanpa alasan.
