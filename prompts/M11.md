# M11 — Hardening & Rilis

## Konteks
M0–M10 selesai; semua fitur ada. Fokus kualitas, performa, keamanan, dokumentasi.

## Tugas
1. **Performa**: audit N+1 (`preventLazyLoading` di dev), tambah index yang kurang berdasarkan query nyata, eager loading di Resource, pastikan cache master/dashboard terinvalidasi benar; review `staleTime` React Query; code splitting route di FE.
2. **Keamanan**: policy di semua endpoint (cek otomatis lewat test yang mengiterasi route), validasi upload (mime sebenarnya, ukuran, nama file aman), unduhan hanya lewat endpoint terotorisasi, rate limit, header keamanan, sanitasi input rich text bila ada, password policy.
3. **Test end-to-end** (feature test BE yang mensimulasikan alur penuh): input temuan → distribusi 2 departemen → assign PIC → tindak lanjut → review (ada yang ditolak, bobot disesuaikan) → evidence → progress → forward → assessment BSR → ronde 2 → SSR → verifikasi SPI → closing. Plus jalur TDTL.
4. **Test visibilitas** menyeluruh PIC/manager lintas endpoint.
5. **Seeder demo** (data contoh lengkap per role) dan `php artisan` command reset demo.
6. **Dokumentasi**: README (setup Laragon, env, perintah), `docs/api.md` ringkas, `docs/deploy.md` (queue, storage link, cache, optimize, backup).
7. Bersihkan komponen duplikat di FE, pastikan semua halaman memakai komponen reusable; hapus kode mati.

## Acceptance criteria
- Seluruh test lolos, termasuk alur end-to-end.
- Tidak ada N+1 pada halaman daftar utama.
- README memungkinkan orang baru menjalankan proyek dari nol.

## Larangan
Jangan menambah fitur baru. Jangan menurunkan aturan visibilitas demi performa.
