# M3 — Input Temuan oleh Admin SPI

## Konteks
M0–M2 selesai. Admin SPI menerima hasil audit eksternal (BPK, BPKP, dll) berupa dokumen, penjelasan, rekomendasi, dan action plan dari auditor. Satu laporan bisa berisi banyak temuan. Setelah lengkap, Admin SPI mengirim ke departemen IA (Manager IA).

## Tugas
**Backend**
1. Tabel `audit_reports`: id, auditor (enum/master: BPK, BPKP, lainnya + nama bebas), report_number, report_date, title, description, created_by.
2. Tabel `findings`: id, audit_report_id, code (otomatis, mis. `TMN-2026-0001`), title, description, recommendation, auditor_action_plan (teks), current_round (default 1), workflow_stage (enum, lihat roadmap, default `DRAFT`), assessment_status (enum, default `BELUM_DITINDAKLANJUTI`), timestamps, soft delete.
3. Tabel `documents` polimorfik reusable (`documentable_type/id`, `label`, original_name, path, mime, size, uploaded_by). Service `DocumentService` untuk upload/validasi/unduh (dipakai ulang M5, M7, M9).
4. API (hanya `admin_spi`): CRUD laporan; CRUD temuan di dalam laporan (banyak temuan sekaligus saat membuat laporan); upload dokumen berlabel pada laporan/temuan; `POST /findings/{id}/send-to-ia` (DRAFT → DIKIRIM_KE_IA, validasi minimal 1 temuan lengkap + minimal 1 dokumen). Temuan yang sudah dikirim tidak bisa diubah kecuali oleh transisi sah.
5. `Manager IA` dan `manager_spi` dapat melihat temuan sesuai tahap (read-only).
6. Panggil `AuditLogger` pada create/update/kirim.
7. Test: validasi, otorisasi, transisi stage, upload file jenis terlarang ditolak.

**Frontend**
8. Halaman daftar laporan/temuan (`DataTable`, filter stage), form tambah laporan dengan temuan dinamis (repeater reusable `RepeatableFields`), `FileUploader` dengan label per dokumen, tombol Kirim ke IA dengan `ConfirmDialog`.
9. Komponen reusable `FindingStageBadge`, `DocumentList` (unduh, label).
10. Halaman detail temuan (kerangka reusable `FindingDetail` yang akan diperluas di milestone berikutnya).

## Acceptance criteria
- Admin SPI dapat membuat laporan dengan >1 temuan, upload dokumen berlabel, dan mengirim ke IA.
- Role lain tidak bisa membuat/mengubah temuan.
- Dokumen hanya dapat diunduh oleh user berhak (private disk).

## Larangan
Jangan implementasi distribusi (M4). Jangan simpan file di disk publik. Jangan buat tabel dokumen terpisah per modul.
