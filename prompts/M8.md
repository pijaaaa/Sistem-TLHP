# M8 — Assessment Manager IA & Ronde

## Konteks
M0–M7 selesai. Manager IA menilai temuan yang MENUNGGU_ASSESSMENT_IA dan menetapkan salah satu dari 4 status: **SSR** (Sudah Sesuai Rekomendasi), **BSR** (Belum Sesuai Rekomendasi), **Belum Ditindaklanjuti** (status default), **Tidak Dapat Ditindaklanjuti**.
Aturan: SSR → diteruskan ke Manager SPI. BSR → ronde baru dengan riwayat tersimpan. Belum Ditindaklanjuti → tidak memicu ronde baru. Tidak Dapat Ditindaklanjuti → case closed, berhenti (alasan wajib).

## Tugas
**Backend**
1. Tabel `finding_rounds`: finding_id, round, started_at, ended_at, assessment_status, assessment_note, assessed_by. Seluruh data ronde (finding_departments, assignees, action_plans, evidence) terikat `round`; ronde lama read-only.
2. `AssessmentService::assess(finding, status, note)` oleh `manager_ia`:
   - SSR: stage → `MENUNGGU_VERIFIKASI_SPI`.
   - BSR (catatan wajib): tutup ronde, `current_round + 1`, buat `finding_departments` baru dari ronde lama (Manager IA boleh mengubah daftar departemen), PIC di-assign ulang oleh manager dept, stage → `DIDISTRIBUSIKAN`.
   - Belum Ditindaklanjuti: simpan status, tidak ada transisi ronde.
   - Tidak Dapat Ditindaklanjuti (alasan wajib): stage → `CASE_CLOSED`, tidak ada transisi lagi.
3. Endpoint riwayat ronde; semua endpoint read menerima parameter `round` (default ronde aktif).
4. Test: tiap status, alasan wajib, ronde lama tidak bisa diubah, ronde baru tidak membawa progress lama, CASE_CLOSED final.

**Frontend**
5. Halaman assessment Manager IA (`AssessmentForm` dengan 4 pilihan + catatan kondisional), tampilkan ringkasan progress semua departemen dan evidence.
6. Komponen `RoundSwitcher` reusable pada `FindingDetail` untuk melihat riwayat ronde (read-only).

## Acceptance criteria
- BSR membuat ronde 2 dengan riwayat ronde 1 tetap dapat dilihat.
- TDTL menutup kasus permanen. SSR muncul di antrian Manager SPI.
- Hanya manager_ia yang bisa assess.

## Larangan
Jangan implementasi closing SPI (M9). Jangan menghapus data ronde lama. Jangan membuat BSR atau Belum Ditindaklanjuti otomatis menutup temuan.
