# M7 — Evidence, Progress, dan Teruskan ke IA

## Konteks
M0–M6 selesai. Setelah tindak lanjut disetujui, PIC mengumpulkan data dan mengunggah laporan/evidence (banyak file berlabel). Evidence harus di-approve Manager Dept agar bobot tindak lanjut itu masuk ke progress. Bila semua tindak lanjut 100%, manager departemen meneruskan temuan ke Manager IA.

## Tugas
**Backend**
1. Tabel `evidence_submissions`: id, action_plan_id, submitted_by, note, status (`DIAJUKAN`, `REVISI`, `DISETUJUI`), review_note, reviewed_by, reviewed_at. Dokumen evidence lewat `documents` polimorfik (label wajib).
2. API PIC: buat/ubah evidence untuk tindak lanjut berstatus MENUNGGU_EVIDENCE/EVIDENCE_REVISI, ajukan.
3. API Manager Dept: approve / revisi (catatan wajib) evidence. Approve → action plan `SELESAI`.
4. `ProgressService`: progress `finding_department` = jumlah bobot tindak lanjut berstatus SELESAI (evidence disetujui). Hanya dihitung saat total bobot aktif = 100. Hitung ulang dan simpan ke `finding_departments.progress` pada tiap approve; progress temuan = rata-rata progress departemen. Invalidasi cache dashboard terkait.
5. Saat progress departemen = 100 → status `SELESAI_100`. `POST /finding-departments/{id}/forward-to-ia` (manager dept) → `DITERUSKAN_KE_IA`. Bila semua departemen pada ronde sudah DITERUSKAN → finding `MENUNGGU_ASSESSMENT_IA`.
6. Evidence yang belum disetujui tidak mempengaruhi progress (test eksplisit).
7. Test: progress sebelum/sesudah approve, revisi evidence berulang, forward hanya jika 100, multi-departemen menunggu semua.

**Frontend**
8. Tab Evidence untuk PIC (upload berlabel, ajukan) dan manager (review). Komponen `ProgressBar` reusable (per tindak lanjut, per departemen, per temuan).
9. Tombol Teruskan ke IA (aktif hanya saat 100%).

## Acceptance criteria
- Progress hanya naik setelah evidence di-approve manager.
- Temuan berpindah ke MENUNGGU_ASSESSMENT_IA hanya setelah semua departemen meneruskan.

## Larangan
Jangan buat assessment (M8). Jangan hitung progress di FE. Jangan hapus evidence yang sudah disetujui.
